


# Задание 1. От исходного кода к байткоду

## Часть 1. Режимы запуска

В интерактивном режиме было выполнено выражение:

``` python
2 + 3 * 4
```

**Прогноз:** сначала выполняется умножение `3 * 4`, затем сложение с
`2`. Результат --- `14`.

В REPL результат отображается автоматически, потому что интерактивный
интерпретатор показывает представление значения каждого введённого
выражения, если оно не равно `None`. При запуске обычного файла
выражение вычисляется, но его значение никуда не выводится. Для
отображения результата нужно явно вызвать `print()`.

## Часть 2. Выражения и инструкции

Рассматриваемый код:

``` python
course = "Python"
hours = 4 * 2
print(f"{course}: {hours} часов")
```

### Выражения

-   `"Python"` --- строковое выражение, состоящее из литерала.
-   `4 * 2` --- арифметическое выражение.
-   `f"{course}: {hours} часов"` --- f-строка: в ней вычисляются
    выражения `course` и `hours`, а затем формируется строка.
-   `course` и `hours` внутри f-строки --- выражения-имена, значения
    которых подставляются в результат.
-   `print(...)` --- вызов функции; в целом вызов также является
    выражением, хотя обычно его используют как часть инструкции.

### Инструкции

1.  `course = "Python"` --- инструкция присваивания.
2.  `hours = 4 * 2` --- инструкция присваивания.
3.  `print(f"{course}: {hours} часов")` --- инструкция-выражение:
    вычисляется вызов `print()`.

### Литералы

-   `"Python"` --- строковый литерал;
-   `4` и `2` --- целочисленные литералы;
-   `f"{course}: {hours} часов"` --- литерал f-строки, содержащий текст
    и поля подстановки;
-   `" часов"` --- текстовая часть f-строки, а не отдельный строковый
    литерал в исходной записи.

### Имена

В результате выполнения присваиваний создаются привязки имён `course` и
`hours` к объектам. Имя `print` не создаётся этой программой: оно уже
доступно как встроенная функция.

## Часть 3. AST и байткод

**Версия Python:** `Python 3.12.10`.

умножение --- оператором `Mult`.

находится в узле `Name` с идентификатором `print`. Конкретное

Python.

### Байткод

В дизассемблированном кода загрузкой констант занимается `LOAD_CONST`,
а вызовом функций `CALL`.

**Фрагмент фактического дизассемблированного кода:**

### Контрольный вопрос

**Почему байткод CPython нельзя считать машинным кодом процессора?**

Байткод CPython --- это набор инструкций для виртуальной машины CPython.
Процессор не исполняет эти инструкции напрямую как собственные машинные
команды. Их обрабатывает интерпретатор CPython, реализованный в машинном
коде. Поэтому байткод зависит от реализации и версии Python, а машинный
код процессора --- от архитектуры процессора и соответствующего набора
команд.

# Задание 2. Имена, объекты и сравнение

Исходный фрагмент:

``` python
a = 1000
b = a
c = int("1000")
```

## Прогноз до запуска


| Выражение | Прогноз | Обоснование                                                      |
|-----------|---------|------------------------------------------------------------------|
| `a == b`  | `True`  | Оба имени связаны с одним и тем же целым числом.                 |
| `a is b`  | `True`  | Присваивание `b = a` связывает `b` с тем же объектом, что и `a`. |
| `a == c`  | `True`  | `int("1000")` создаёт целое число со значением `1000`.           |
| `a is c`  | `False` | `c` получает результат отдельного преобразования.                |

Последнее предположение не является переносимой гарантией языка.
Проверять равенство числовых значений нужно через `==`, а не через `is`.

**Фактический вывод:**
```
Типы: <class 'int'> <class 'int'> <class 'int'>
Идентификаторы: 1880647319728 1880647319728 1880644688176
a == b: True
a is b: True
a == c: True
a is c: False
```

## Схема имён и объектов

``` mermaid
flowchart LR
  a["a"] --> A["объект int: 1000"]
  b["b"] --> A
  c["c"] --> C["объект int: 1000"]
```

Схема показывает ожидаемую связь имён после выполнения трёх
присваиваний. `a` и `b` ссылаются на один объект, потому что `b = a` не
копирует объект. `c` связан с результатом отдельного вызова
`int("1000")`. Не следует строить логику программы на предположении о
том, что `c` обязательно будет или не будет тем же объектом, что `a`.

## Равенство и идентичность

Оператор `==` проверяет равенство значений согласно правилам сравнения
соответствующих типов. Оператор `is` проверяет, являются ли два
выражения ссылками на один и тот же объект.

Например, `a == c` проверяет, равны ли числа, а `a is c` --- обозначают
ли имена один объект.

`type(x)` возвращает объект типа, к которому относится `x`. `id(x)`
возвращает идентификатор объекта, уникальный для него в течение времени
жизни объекта. В CPython этот идентификатор обычно связан с адресом
объекта, но полагаться на это как на общее правило Python не следует.

## Значение `None`

После присваивания:

``` python
c = None
print(c is None)
```

результат проверки --- `True`. Для проверки `None` принято использовать
`is None` или `is not None`, поскольку `None` --- специальный
объект-синглтон.

## Эксперимент со строками

``` python
first = "python"
second = "py" + "thon"

print(first == second)
print(first is second)
```

Прогноз для `first == second`: `True`, поскольку строки имеют одинаковое
содержимое.

Результат `first is second` может зависеть от реализации и оптимизаций:
интерпретатор может повторно использовать объект строки (например,
благодаря интернированию или оптимизации констант). Поэтому нельзя
использовать `is` для сравнения содержимого строк.

**Фактический вывод:**
```
True
True
```

### Правило применения операторов

-   Использовать `==`, когда нужно сравнить значения чисел, строк и
    большинства других объектов.
-   Использовать `is`, когда нужно проверить идентичность объектов;
    типичный пример --- `x is None`.

## Контрольные вопросы

**Создаёт ли `b = a` копию объекта?**\
Нет. Эта инструкция связывает имя `b` с тем же объектом, на который
указывает `a`.

**Что возвращают `type()` и `id()`?**\
`type()` возвращает тип объекта. `id()` возвращает его идентификатор,
уникальный в течение времени жизни объекта.

**Почему `None` сравнивают через `is`, а числа и строки --- через
`==`?**\
`None` обозначает единственный специальный объект, поэтому проверяют
идентичность с ним. Для чисел и строк обычно важны значения, а не то,
представлены ли они одним объектом.

# Задание 3. Числовые типы, операции и преобразования

## Эксперимент A. `int` и арифметические операторы

Для `x = 17` и `y = 5` прогноз:

| Выражение | Значение  | Тип     |
|-----------|-----------|---------|
| `x + y`   | `22`      | `int`   |
| `x - y`   | `12`      | `int`   |
| `x * y`   | `85`      | `int`   |
| `x / y`   | `3.4`     | `float` |
| `x // y`  | `3`       | `int`   |
| `x % y`   | `2`       | `int`   |
| `x ** y`  | `1419857` | `int`   |

Обычное деление `/` возвращает результат типа `float`, даже если оба
операнда --- `int`. Деление нацело `//` возвращает частное, округлённое
вниз. Для положительных `17` и `5` результат равен `3`. В общем случае
`//` --- именно округление вниз, а не простое отбрасывание дробной
части.

## Эксперимент C. `float`

Для:

``` python
result = 0.1 + 0.2
```


-   `result` отображается как `0.30000000000000004`;
-   `result == 0.3` даёт `False`;
-   `result - 0.3` даёт небольшую ненулевую разность,
    `5.551115123125783e-17`;
-   `math.isclose(result, 0.3)` даёт `True`.

Числа типа `float` обычно представлены в формате двоичной арифметики с
плавающей точкой. Десятичные дроби `0.1` и `0.2` не имеют точного
конечного двоичного представления, поэтому при вычислениях возникает
небольшая погрешность округления.

Для сравнения приближённых результатов следует применять
`math.isclose()` с подходящими относительным и/или абсолютным допусками.
Если требуется точная десятичная арифметика, например для финансовых
расчётов, может подойти `decimal.Decimal`.

## Эксперимент D. `bool`, `complex` и преобразование типов

| Выражение        | Значение | Тип       |
|------------------|----------|-----------|
| `int("42")`      | `42`     | `int`     |
| `float("3.14")`  | `3.14`   | `float`   |
| `str(2026)`      | `"2026"` | `str`     |
| `bool(0)`        | `False`  | `bool`    |
| `bool(-1)`       | `True`   | `bool`    |
| `bool("")`       | `False`  | `bool`    |
| `bool("False")`  | `True`   | `bool`    |
| `complex(2, -3)` | `(2-3j)` | `complex` |

`bool("False")` возвращает `True`, потому что непустые строки считаются
истинными. Python не интерпретирует содержимое строки как текстовое
написание логического значения при вызове `bool()`.

Для `z = complex(2, -3)` действительная часть равна `2.0`, а мнимая ---
`-3.0`. Их можно получить через `z.real` и `z.imag`.

### Контрольные вопросы

**Почему обычное деление двух `int` возвращает `float`?**\
Оператор `/` предназначен для обычного деления и сохраняет дробную часть
результата, поэтому результат имеет тип `float`.

**Чем отличаются `int("42")` и `int(42.9)`?**\
`int("42")` разбирает строку, содержащую запись целого числа.
`int(42.9)` преобразует вещественное число в целое, отбрасывая дробную
часть в направлении нуля; результат --- `42`.

**Какие значения из эксперимента D являются falsy?**\
`bool(0)` и `bool("")` дают `False`. Остальные перечисленные значения
дают `True`.

# Задание 4. Строки, Unicode и форматирование

Исходные данные:

``` python
student = "Анна Смирнова"
course = "Основы программирования на Python"
completed = 7
total = 10
```

## Индексация и срезы

-   Первый символ `student[0]` --- `А`.
-   Последний символ `student[-1]` --- `а`.
-   Имя: `student[:4]` → `Анна`.
-   Фамилия: `student[5:]` → `Смирнова`.
-   Верхний регистр: `student.upper()` → `АННА СМИРНОВА`.
-   Нижний регистр: `student.lower()` → `анна смирнова`.
-   Инициалы: `student[0] + "." + student[5] + "."` → `А.С.`.
-   Обратный порядок символов курса: `course[::-1]`.

Срез имеет форму `text[start:stop:step]`: `start` --- индекс начала,
`stop` --- граница, не включаемая в результат, `step` --- шаг. При
отрицательном шаге строка обходится в обратном направлении.

## Форматирование результата

Процент выполнения:

``` python
percent = completed / total * 100
```

Ожидаемая строка:

``` text
Анна Смирнова — Основы программирования на Python: 7/10 (70.0%)
```

Три способа форматирования:

``` python
"%s — %s: %d/%d (%.1f%%)" % (student, course, completed, total, percent)
"{} — {}: {}/{} ({:.1f}%)".format(student, course, completed, total, percent)
f"{student} — {course}: {completed}/{total} ({percent:.1f}%)"
```

**Фактический вывод:**
``` text
Анна Смирнова — Основы программирования на Python: 7/10 (70.0%)
Анна Смирнова — Основы программирования на Python: 7/10 (70.0%)
Анна Смирнова — Основы программирования на Python: 7/10 (70.0%)
```

## Unicode

Для `symbol = "Я"`:

-   `symbol` --- `Я`;
-   `ord(symbol)` --- `1071`;
-   `chr(ord(symbol))` --- `Я`;
-   `symbol.encode("utf-8")` --- `b'\\xd0\\xaf'`;
-   `len(symbol.encode("utf-8"))` --- `2`.

В Python строка хранит последовательность Unicode-кодовых точек, а UTF-8
кодирует символы в последовательность байтов. Поэтому длина строки и
длина её UTF-8-представления в байтах могут различаться.

**Фактический вывод:**
``` text
symbol='Я'
ord(symbol)=1071
chr(ord(symbol))='Я'
symbol.encode('utf-8')=b'\xd0\xaf'
len(symbol.encode('utf-8'))=2
```

## Неизменяемость строк

Попытка изменить строку по индексу, например:

``` python
student[0] = "О"
```

вызывает `TypeError`, потому что строки в Python неизменяемы. Нельзя
заменить отдельный символ внутри уже существующего строкового объекта.
Методы вроде `.upper()` не изменяют исходную строку, а возвращают новую
строку с преобразованным содержимым.

**Сообщение об ошибке:** `TypeError: 'str' object does not support item assignment`

### Контрольные вопросы

**Почему `len(symbol)` и `len(symbol.encode("utf-8"))` могут
различаться?**\
`len(symbol)` считает элементы строки (в данном примере ---
Unicode-кодовые точки), а длина закодированного объекта `bytes` считает
байты. Один символ UTF-8 может занимать несколько байтов.

**Что означают границы и шаг в `text[start:stop:step]`?**\
`start` задаёт начальную позицию, `stop` --- исключаемую конечную
границу, `step` --- расстояние между выбираемыми позициями.
Отрицательный шаг позволяет двигаться справа налево.

**Почему строка неизменяема, хотя `.upper()` возвращает изменённый
текст?**\
Метод не меняет исходный объект, а создаёт и возвращает новую строку.
Исходная строка остаётся прежней.

# Задание 5. Информационная карточка вычислительного эксперимента

| `modulus_squared` | `float`   |
| `has_runs`        | `bool`    |

Если в программе использованы другие имена, замените таблицу на
соответствующую вашему коду. Типы зависят от конкретных выражений
присваивания.

## Разбор арифметической строки

Рассмотрим:

``` python
total_seconds = runs * duration
```

-   `total_seconds`, `runs`, `duration` --- имена;
-   `=` --- оператор присваивания;
-   `*` --- оператор умножения;
-   отдельные числовые литералы в этой строке отсутствуют;
-   вызовов функций в этой строке нет.

Выражение `runs * duration` вычисляется, после чего имя `total_seconds`
связывается с полученным объектом типа `float`.

## Почему необходимо преобразовывать результат input()

Функция input() всегда возвращает строку (str),
даже если пользователь вводит число. Например,
при вводе 8 результатом будет строковый 
объект "8", а не целое число 8.
Поэтому перед арифметическими вычислениями введённые данные необходимо
преобразовать в соответствующие числовые типы с помощью int() или float():
```python
runs = int(input("Количество запусков: "))
duration = float(input("Длительность одного запуска: "))
```
Без преобразования Python будет воспринимать введённые данные как строки.
Например, операция "8" + "2" даст строку "82", поскольку оператор + для 
строк выполняет конкатенацию, а не сложение чисел. При попытке 
выполнить "8" * 2 получится "88" — повторение строки, а не числовое умножение.
Другие арифметические операции со строками, например "8" - "2", вызовут TypeError.

## Контрольный вопрос

**Что изменится после повторного присваивания нового значения уже
существующему имени?**

Например, после `runs = 8`, если выполнить `runs = 10`, имя `runs` будет
связано с объектом, представляющим число `10`. Само имя не содержит
значение и не превращает старый объект в новый. Другие имена, которые
ранее ссылались на старый объект, не изменятся автоматически. Если на
старый объект больше нет ссылок, он может стать доступным для удаления
сборщиком мусора.

# Итоговый вывод

В ходе работы были исследованы три интересные особенности Python.

1.  **Имя --- это ссылка на объект, а не контейнер с фиксированным
    значением.** Присваивание `b = a` создаёт ещё одну привязку к
    объекту, а не копию. Это помогает понять различие между `==` и `is`.
2.  **Числа и операции имеют особенности, которые не всегда очевидны по
    записи выражения.** Например, `/` возвращает `float`, целые числа
    могут быть очень большими, а вычисления с `float` могут иметь
    небольшую погрешность.
3.  **Строки --- неизменяемые Unicode-объекты, а кодирование в байты ---
    отдельная операция.** Один символ может занимать несколько байтов в
    UTF-8; методы преобразования строк возвращают новые значения, а не
    меняют исходную строку.

Эти эксперименты показывают, что для понимания Python важно различать
исходный текст, выполняемые инструкции, объекты, имена и типы данных.
